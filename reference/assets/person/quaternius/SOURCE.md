# Universal Base Character

This directory vendors the male character subset from Quaternius'
**Universal Base Characters – Standard** package.

- Source: https://quaternius.com/packs/universalbasecharacters.html
- Download page: https://quaternius.itch.io/universal-base-characters
- Model: `Superhero_Male_FullBody`
- License: CC0 1.0 Universal; see `License_Standard.txt`
- Retrieved: 2026-07-31

Only the glTF, binary mesh, and textures referenced by that glTF are included.
The two `*_png.png` files duplicate their upstream normal maps because the
upstream glTF uses those URI spellings.
